# Calculadora de peptídeos

Calculadora web de reconstituição: informa quantas unidades (UI) puxar numa seringa de insulina U-100 a partir da quantidade de peptídeo no frasco, da água adicionada e da dose desejada.

## Como usar

Abra `index.html` no navegador (funciona no iPhone, sem instalar nada) ou acesse a página publicada pelo GitHub Pages.

Campos:

- **Peptídeo no frasco** (mg)
- **Água bacteriostática adicionada** (mL)
- **Dose desejada** (mg)
- **Seringa** (0,3 mL, 0,5 mL ou 1 mL)

## Cálculo

- Concentração (mg/mL) = mg do frasco ÷ mL de água
- Volume da dose (mL) = dose ÷ concentração
- UI = volume em mL × 100 (seringa U-100)

A calculadora também avisa quando a dose não cabe na seringa, quando o volume fica abaixo da menor marca e quando a dose é maior que o conteúdo do frasco.

## Aviso

Ferramenta de conversão matemática. A dose em si deve vir de um profissional de saúde. Confira sempre os valores do rótulo do frasco.
